### 核心洞察:两家在"相反的轴"上各赢一半

- **Meshy = 更干净的几何**:切片 16/16 全 manifold,**焊接档直接绑定 14/16**(不需重拓扑),开箱即是生产就绪网格。适合直接进管线。
- **Tripo H3.1 = 更贴合的形状**:VLM 语义 **4.0 vs Meshy 2.0**,输出与参考图的形状匹配明显更好;但**开箱仍需重拓扑才能绑**(0/7 焊接、7/7 重拓扑)——SparseFlex 的特征在最新旗舰上依然成立,和社区"Tripo 要清理"的口碑一致。

一句话:**Meshy 为"干净可绑可打印"优化,Tripo H3.1 为"形状/细节保真"优化。** 这直接对应两家的战略打法——Meshy 订阅制、把绑定做成免费钩子(所以几何要能直接绑);Tripo API 收入导向、押注生成保真。

## 诚实边界(采购决策必读)

1. **样本量小**:H3.1 n=7(fal 到账时间差所致)、Meshy n=16(积分耗尽)。CI 已给出;H3.1 的 CI(87–94)偏宽但仍稳落第一梯队。
2. **case 子集不完全重合**:H3.1 的 7 个 case 是分层集的后 7 个,Meshy 的 16 个是另一子集,直接逐 case 配对比较受限;此处为"梯队 + 中位数"结论,非配对检验。
3. **VLM 语义是单一信号**(判官 n=13):Meshy 2.0 可能部分受"无纹理渲染"影响,不宜过度解读;但 4.0 vs 2.0 的差距足够大,值得记录并在后续人工盲评中复核。
4. 测的是**默认档开箱输出**;各家 quad/低模/高清贴图增强未启用。

## 结论

在"生产可用性"这把尺子上,**Tripo H3.1 与 Meshy 6 统计并列于第一梯队(~93)**,但可采购的差异不在总分,而在:
- 要**直接进绑定/打印管线** → Meshy 开箱更干净(直绑 14/16、切片全通)
- 要**形状/细节最贴合输入** → Tripo H3.1 更强(语义 4.0),但预算里要留一道**重拓扑**工序

公开 arena 偏好纹理观感的盲区,在这里被两条线补上了:Meshy 的高几何分 + 低语义分,正是"好看/干净"与"贴合/可用"错位的实证。
