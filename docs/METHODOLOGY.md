> 并经自检/真跑验证),下半部分为分场景缺口审计与优先级路线图。

# 第一部分:现状方法论(as-built)

## 1. 协议五原则

1. **同输入(像素级)**:每 case 用固定种子的 FLUX 参考图(PNG),跨 run 可
   逐位复现 → 任何时候补测新模型都与历史严格可比
2. **官方渠道优先**:一方 API 优先(Tripo/Meshy/方舟),无一方 REST 才走托管
   (fal);模型版本逐一 pin 在 config
3. **盲评**:几何指标无需盲(不可被偏好污染);人工/VLM 语义评走匿名洗牌画廊
4. **中位数聚合**:单个幸运/灾难 case 不动排名;完成率并列呈现
5. **勘误公开**:每次尺子被校准都记录在案(AUDIT.md 累计 6 条),证据分 A/B/C 级

## 2. 测量管线(每个网格)

```
下载(魔数校验/zip解包) → 载入拼合 → UV检测(焊前) → 精确位置焊接(已被
真实GLB二进制解析验证) → 指标提取 → 双profile评分 → 多视图渲染 → 语义判官
```

**指标层**(全部客观、代码化、阈值集中一处):
- **闭合三档**:原始 buffer / 焊接后 / 一键修复后(fill-holes 探测)
- **缺陷量级**:开放边+非流形边 / 总边数(log10 连续曲线,替代二元悬崖)
- **部件闭合度**:closed_face_fraction(多部件资产按"处于闭合部件的面占比")
- **拓扑**:sliver 率、纵横比 p95、退化/重复面、法线一致性、面密度
- **可绑定代理**:部件闭合度、碎片度、内部面射线探针、双边对称残差(角色)
- **资产完整度**:UV(焊前检测)/法线/材质
- **预算适配**:面数 vs 实时带(1.5k-150k,带外对数减半)
- **性能**:生成时延(已入报告)

**评分层(v2)**——两个 profile 并列输出,永不混合:
- **打印/仿真榜**:闭合(量级).40 + 拓扑 .35 + 可绑定 .25
- **游戏资产榜**:闭合 .25 + 拓扑 .30 + 可绑定 .20 + 预算 .15 + UV .10
- **语义保真**(独立轴,不进几何分):VLM 判官 1-5 + 人工盲评画廊

## 3. 工程保障

失败隔离(单家失败不污染他家)、零成本失败设计(提交失败不扣费)、字段/版本
自愈、按 provider 超时、诊断探针(fal_diag)、产物全存档、离线自检
(selftest 验证排序正确性后才允许花钱)。

## 4. 已知能力边界(诚实条款)

- **强区分"架构阵营"**(等值面构造闭合 / SparseFlex 细节优先 / 轻量 LRM),
  **弱区分"阵营内执行力"**(第一梯队 90-94 的名次差小于噪声)
- n=4/模型时只支持"梯队"结论;黑盒测的是**产品输出**,无法区分生成 vs 静默后处理
- 测的是"默认档开箱输出";各家付费增强项(quad/低模/高清贴图)未启用

# 第二部分:分场景缺口审计(本轮新增)

## 场景 A:3D 打印 / 制造

| 缺口 | 为什么重要 | 实现难度 | 优先级 |
|---|---|---|---|
| **切片器实测**(PrusaSlicer/Bambu CLI 无头跑) | "slicer pass" 是该场景的 ground truth,厂商都在引用这个口径(Meshy 自报 97%),我们应有同口径数据 | 中(CI 装 slicer CLI) | **P0** |
| **自相交检测** | 自相交网格布尔/切片会错,我们完全没测 | 中(需 manifold/libigl) | P1 |
| **最小壁厚** | FDM 失败主因之一;细支/薄壁是 AI 生成重灾区 | 中(SDF 采样) | P1 |
| 伪柄/genus 异常 | 混元 c01 genus=25,MC 噪声柄影响打印后处理 | 低(已记录 genus,报告化即可) | P2 |
| 悬垂/支撑体积 | 打印成本驱动 | 高 | P3 |

## 场景 B:游戏 / 实时

| 缺口 | 为什么重要 | 实现难度 | 优先级 |
|---|---|---|---|
| **绑定实测**(Blender headless 自动权重+骨骼弯曲测试) | 现在全是代理指标;"关节弯曲 30° 是否塌陷"才是真答案(口碑批评正集中于此) | 中(bpy) | **P0** |
| **UV 质量**(不只"有没有"):重叠率、岛数、texel 密度均匀性 | UV 有但烂 = 依然要重展;当前 0.10 权重只奖励"存在" | 中 | P1 |
| **quad 模式专项轮**:各家 quad/低模选项打开对打 | 游戏美术实际用的是 quad 输出;当前只测三角默认档,漏掉了各家真正为游戏准备的产品面 | 低(config 加参数轮) | **P0** |
| glTF validator(Khronos CLI)错误数 | "引擎能不能导入"的客观下界 | 低 | P1 |
| 减面鲁棒性(LOD-ability):减到 10% 后的形变量 | LOD 管线必经;稠密雕塑与干净拓扑在此分化 | 低(已有 fast-simplification+可加 Hausdorff) | P2 |
| 翻转法线占比 | 现在只有全局 winding 布尔 | 低 | P2 |
| 预算带按子场景细分(手游<30k/PC hero<150k) | 当前单一带宽一刀切 | 低 | P3(避免过度切分) |

## 场景 C:影视 / 高保真(**当前缺失的第三 profile**)

稠密在这里是**优点**(Rodin/H3.1 的 50 万-200 万面正是为此),UV/贴图刚需,
细节丰富度是核心价值——现有两榜要么惩罚稠密(游戏榜)要么无视细节(打印榜)。

| 缺口 | 实现路径 | 优先级 |
|---|---|---|
| 细节保真度量化 | 短期用语义判官分项(细节维度 1-5);长期可加曲率熵/多尺度法线能量 | P1 |
| 贴图质量轴(分辨率/PBR 完整性/烘焙质量) | 已记录材质存在性,扩展为分辨率+贴图套数 | P2 |
| 独立"影视/DCC 榜" | 闭合(量级)+细节+UV+贴图 加权 | P2(等细节指标就绪) |

## 场景 D:仿真 / 具身智能(Seed3D 的主场,当前未独立成榜)

| 缺口 | 说明 | 优先级 |
|---|---|---|
| 质量属性可算性 | is_volume(已有)+ 惯性张量可算 + 质心位置合理 | P2 |
| 碰撞友好度 | 凸包体积比(solidity)、凸分解片数估计 | P2 |
| 真实尺度 | 各家输出尺度不一,auto_size 类参数未启用/未检 | P3 |

## 跨场景(方法学本身)

| 缺口 | 说明 | 优先级 |
|---|---|---|
| **统计功效**:40 case 全量 + 每 case 2-3 次生成 + 自助法置信区间 | 把"梯队"结论升级为统计结论;CI 重叠的名次一律报"并列" | **P0** |
| **语义轴落地**:VLM 判官首个全量轮 | 梯队内区分的主要希望;判官需自校验(与人工盲评抽样对齐) | **P0** |
| 生成稳定性(同输入重复生成的方差/同 seed 确定性) | 生产采购关心"稳定交付",Tripo 有 model_seed 可测确定性 | P1 |
| 内部面探针细化:区分"闭合内部部件"(合法)vs"开放碎片"(垃圾) | 现有探针混淆两者,对多部件资产偏严 | P1 |
| 成本列入报告(每资产 $) | 数据在 VENDORS.md,应进 report 并列 | P2 |
| 判官偏差审计 | VLM 判官对渲染风格/视角的偏好需抽样对照人工 | P2 |

## 优先级汇总(P0 = 发布前应完成)

1. **40-case + 重复生成 + 置信区间**(统计功效)——~$40-60
2. **VLM 语义判官全量首跑**(梯队内区分)——已接线,随大轮自动跑
3. **quad 模式专项轮**(游戏场景的真产品面)——config 参数轮,~$5
4. **切片器实测**(打印场景 ground truth)——CI 装 PrusaSlicer CLI
5. **Blender 绑定烟测**(游戏场景 ground truth)——bpy headless

其中 1+2 只需充值后点一次大轮;3 是一次 config 变体轮;4/5 是两个中等开发项。
