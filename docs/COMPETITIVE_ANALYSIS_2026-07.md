## 一、执行摘要(一页版)

**测什么**:生产可用性(水密 / 拓扑 / 可绑定),不是"好看"。这对应付费
客户的真实验收口径,也是公开 arena(偏好纹理观感)的系统性盲区。

**七个厂商、十一个模型**的实测格局:

1. **第一梯队(生产分 ~90+,统计并列)**:Meshy 6、Tripo H3.1(修复后管线)、
   腾讯混元 v2/v3.1、影眸 Rodin 2.5、微软 TRELLIS 1、字节 Seed3D 2.0。
   梯队内名次差小于噪声,**不应读作排名**。
2. **头对头终局(2026-07-15 专门轮)**:发布轮口径 Tripo H3.1(92.9)与
   Meshy(93.0)打平;**勘误 #8 混合口径(实测绑定计入)估算后 Meshy ~94.4
   领先 H3.1 ~89.7**——H3.1"需重拓扑才能绑"的真实代价开始计分,但 H3.1
   n=7 的 CI 较宽,领先是否显著待下轮实跑确认。两家仍**赢在相反的轴**:
   Meshy 开箱直绑 14/16 + 切片 16/16 全通;H3.1 形状保真 VLM 4.0 vs 2.0。
3. **架构决定水密**:SDF/占用场 + Marching Cubes 阵营(Rodin/混元/Seed3D)
   水密是"构造性免费赠品";Tripo SparseFlex 开放面架构换细节、牺牲闭合——
   这是路线选择,不是执行力差距。
4. **营销宣称 vs 实测**:Seed3D"仿真就绪"基本兑现(闭合+全场最佳对称,代价
   是全场最慢);Tripo P1"干净拓扑"宣称**不成立**(水密 4/38;但直绑与预算
   适配全场最佳级,主口径游戏榜 67.4——见勘误 #8);
   H3.1"高保真"兑现了(细节+语义双高)。
5. **经济性极值**:混元开源自托管 **$0.009/次**(比任何托管渠道便宜 90%+),
   是规模化用户的终局选项;商业 API 集中在 $0.2-0.75/次。
6. **低模赛道专项(v1.2 新增)**:Tripo 的 quad 附加项(+7.5cr)**真的修复了
   直绑问题**(焊接档 0/7 → 7/8),且语义保持 4.0——"生产就绪当付费项卖"的
   策略在技术上成立;但这也让 **H3.1+quad(~$0.375)在每个维度上击败了自家
   更贵的 P1(~$0.45)**,P1 在低模主场四家中垫底,产品线定位出现内部矛盾。
   另:Rodin quad 模式语义崩到 1.0(形状换布线),Tripo quad 无此代价——
   "布线干净 vs 形状像"是 Rodin 的特定取舍,不是行业定律。

订阅积分不能用于 API。

### Meshy —— 订阅平台,几何干净是商业模式的必然

| 产品线 | 价 | 卖点 |
|---|---|---|
| meshy-6 | 素模 5-20 cr + 贴图 10 cr(Pro 档 ≈$0.4-0.6 整链) | 两段式,纹理主打 |
| **自动绑定 + 动画** | **0 cr 免费** | 生态钩子 |
| 重贴图/重拓扑 | 按任务 | 管线补全 |

**收费哲学**:订阅量优先(Free 100cr / Pro $20 1000cr / Studio $60)。
把绑定做免费钩子 → 倒逼几何必须能直接绑 → **实测直绑 14/16 全场最佳**,
商业模式与技术表现互相印证。

### 影眸 Rodin —— 高端质量路线,门槛即定位

- Gen-2.5:官方 $0.75 列表(订阅折后 ~$0.4-0.5),HighPack(4K 贴图+高模)+1cr

  实际是其"低门槛入口"(渠道价差最典型案例)
- 实测:91.5 分、水密 4/4(架构赠品)、对称好;**拓扑质量是第一梯队里最弱**
  (审计结论:高分靠架构红利+对称,不靠拓扑执行力)

### 字节 Seed3D —— 大厂生态,"仿真就绪"差异化

- 2.0:¥2.40/次($0.33),按**成功**计费;输出 glb/obj/usd/usdz、部件结构
- 仅火山方舟(曾短暂上 fal 已下架),不开源
- 实测:90.6 分、对称残差 0.0013 全场最佳级、闭合达标 —— **宣称基本兑现**;
  代价:**全场最慢**(硬表面 case 两轮均超时 >15-30 分钟)

### 腾讯混元 —— 开源+闭源双轨,经济性终局

- 闭源 v3.x Pro:20 积分/次(LowPoly+PBR 35 积分),自定义面数 40K-1.5M
- **开源 v2/v2.1/v2.5:自托管 $0.009/次**(SaladCloud 实测,比 fal 便宜 94%)
- 实测:v2 是早期轮次**唯一稳定水密**的模型(93.6*),v3.1 Pro 90.4* 守住
  水密但未显著超越 v2 —— 开源版本身已是第一梯队,重度用户自托管即终局

### 微软 TRELLIS —— 研究开源,无商业承诺

- MIT 权重免费,fal ~$0.05-0.15,无 SLA、无官方渠道
- T1 实测 91.2*(开源黑马);T2 低分(37.6*)但曾受"仅其一家强制减面"的
  配置不公,**待复测,当前不下结论**
- splat 双输出正是"arena 好看偏好"的技术源头之一

### 4.4 勘误 #8 混合口径(实测绑定计入)——对全体对称重算

可绑定分改为"结构代理 50% + Blender 实测真绑 50%"后,**同一把尺子对四个
模型的修正方向不同**(这正是它公平的证据):

| 模型 | 可绑定:代理 → 混合 | 生产分:发布轮 → 混合ᵉ | 游戏榜:发布轮 → 混合ᵉ | 方向 |
|---|---|---|---|---|
| Meshy | 91.6 → **95.8** | 93.0 → **~94.4** | 84.0 → **~85.7** | ↑ 实测直绑印证代理 |
| Tripo H3.1 | 91.2 → **78.1** | 92.9 → **~89.7** | 80.6 → **~78.0** | ↓ 需重拓扑的代价开始计分 |
| Tripo v3.0 | 80.4 → **72.7** | 87.4 → **~83.0** | 78.0 → **~74.4** | ↓ 同上 |
| Tripo P1 | 44.7 → **68.1** | 47.6 → **~53.8** | 63.1 → **~67.4** | ↑ 实测好绑,代理曾冤枉 |

*ᵉ 中位数级估算(用各轮已发布的中位数重组;混合的正式实现是逐网格计算后
再取中位,已进入管线,下一轮实跑自动产出精确值)。*

**这次修正的叙事变化**:
- 头对头从"打平"变为 **Meshy 估算领先(~94.4 vs ~89.7)**——H3.1 的代理分
  曾因"闭合好"被高估,而它实际 0/7 直绑;修正同时抬了 P1、压了 H3.1,
  **同一机制、方向相反**,不存在偏袒。
- H3.1 n=7 CI 较宽(87-94),领先是否统计显著待下轮实跑确认;"两家赢在
  相反的轴"(几何干净 vs 形状保真)的结构性结论**不受影响**。

|---|---:|---:|---:|---:|
| 游戏榜中位(主口径) | **87.9** | 83.1 | 76.8 | ~67.4ᵉ |
| 生产分中位 | 83.7(CI 70-97) | **92.4**(CI 91-93) | 66.7 | ~53.8ᵉ |
| **绑定·焊接档直绑** | **7/8** | 6/7 | 1/1 | 33/38 |
| 切片器 manifold | 4/8 | **7/7** | 0/1 | 5/38 |
| 语义保真(VLM) | **4.0** | **1.0(全场历史最低)** | 4.0 | 4.0 |
| 预算适配(实时带) | 100 | 30(quad 输出仍重,非真低模) | 100 | 100 |
| 单价(官方) | ~$0.375(30+7.5cr) | ~$0.45(fal) | 未定价核实(t2 积分高) | $0.4-0.5 |
| 输出格式 | **FBX(需转换!)** | glb | glb | glb |

*† meshy_lp 仅 1 个样本(Meshy 积分再次耗尽,7×402),数字只作方向参考。
ᵉ = 勘误 #8 混合口径估算。Rodin quad 严格说不在"低模"带(预算适配仅 30),
是"quad 布线的稠密网格",列入供对照。*

**三个悬念的答案**:

1. **quad 附加项修复了 Tripo 的直绑问题** ✅:H3.1 默认档焊接直绑 0/7,
   +quad 后 **7/8**,语义保持 4.0,游戏榜 80.6→87.9。代价:水密从 100 掉到
   82.4(焊接档 4/8——重拓扑引入开缝)、时延翻倍(150s→340s)、**输出变成
   FBX**(管线要多一道格式转换,买附加项前没人告诉你)。结论:"生产就绪当
   付费项卖"技术上成立,Tripo 的游戏资产正解是 **H3.1+quad,不是 P1**。
2. **P1 在自己的主场垫底** ❌:游戏榜 ~67.4,输给自家 H3.1+quad(87.9)、
   Rodin quad(83.1)、甚至 n=1 的 Meshy smart-topo(76.8)。且 P1 单价
   (~$0.45)比 H3.1+quad(~$0.375)**更贵**。P1 的"原生低模生成"路线目前
   没有兑现出可测量的优势——同一家公司的"稠密+付费重拓扑"路线全面更优。
3. **"布线干净 vs 形状像"不是行业定律**:Rodin quad 语义崩到 1.0(为布线
   牺牲形状,全场历史最低),但 Tripo quad 保持 4.0。这是 Rodin 重拓扑实现
   的特定缺陷,不是 quad 化的必然代价——也再次印证 Rodin"架构红利掩盖
   执行力短板"的审计结论。

### 5.1c 修复工时锚:绑定管线的"全成本"(v1.4 新增)

把实测档位换算成 DCC 修复工时(焊接即绑 0h / 重拓扑 3h / 绑定失败 8h /
修复档水密 0.5h / 不可修复 2h / 缺 UV 1h),按 TA $30/h 计:
**全成本 = 生成单价 + 期望修复工时 × 时薪**。这回答的是"要进**绑定管线**,
一个资产真正花多少钱"(打印管线看 5.1b 的 $/可打印即可):

| 模型 | E[修复工时] | 修复成本 | **全成本/资产** | 生产分 |
|---|---:|---:|---:|---:|
| **Meshy 6** | 0.38h | $11.25 | **$11.75** | 93.0 |
| Rodin quad | 0.43h | $12.86 | $13.31 | 92.4 |
| H3.1+quad | 1.38h | $41.25 | $41.62 | 83.7 |
| Tripo P1 | 2.45h | $73.42 | $74.22 | 47.6 |
| Tripo v3.0 | 2.72h | $81.67 | $81.97 | 87.4 |
| **Tripo H3.1** | 3.00h | $90.00 | **$90.30** | 92.9 |

**关键发现:经济锚与生产分几乎不相关(Spearman 0.26)——两把尺子回答不同
问题**。生产分说"出厂几何多好":H3.1 92.9 顶级;全成本说"进绑定管线花多少":
**H3.1 反而全场最贵($90.30,因为 7/7 需 3 小时重拓扑)**,是 Meshy 的 7.7 倍。
这正是外部框架"修复成本锚定"的价值:分数看不见的劳务成本被暴露了。工时表
与时薪是显式参数(`src/analysis/repair_cost.py`),不服可改数重算——权重
从"可辩论"变成了"可证伪"。

## 八、战略格局解读

1. **架构阵营决定了半张榜单**:等值面构造闭合(Rodin/混元/Seed3D)vs
   SparseFlex 细节优先(Tripo)vs 轻量 LRM(TripoSR)。基准强区分阵营、
   弱区分阵营内执行力——采购时先选阵营(=选默认档的取舍),再选厂商。
2. **商业模式与技术表现互相塑造**:Meshy 靠订阅+免费绑定钩子 → 几何必须
   干净;Tripo 靠按件 API + 附加项 → 把重拓扑做成了付费功能(quad +7.5cr)
   而不是默认品质;Rodin 用 $120 门槛做品牌筛选;字节/腾讯用生态与开源
   换位置。**输出特征不是偶然,是商业模式的投影。**
3. **中国厂商占第一梯队多数**(混元×2、Rodin、Seed3D + Tripo H3.1),
   微软 TRELLIS 是唯一开源国际选手;"商业 vs 开源"的质量差已基本抹平,
   剩下的是 SLA、渠道与工具链之差。
4. **公开 arena 与生产口径的错位被双向证实**:Meshy 高几何分+低语义分,
   Tripo 高语义分+需清理——任何单一榜单(包括本报告的单一总分)都会
   掩盖这种结构性取舍,**必须分轴读**。
