# 深度审计:Tripo 实测垫底 vs 市场口碑顶级——差异从何而来

> 2026-07-14。方法:内部法医复查(三轮 run 的逐边几何指纹)+ 12 个研究代理的
> 外部取证(453 次检索,含对真实 Tripo GLB 的二进制解析),全部经对抗性复核。
> 结论驱动了评分体系 v2(已实施)。

## 一句话结论

差异 = **我们的尺子错了一半(v1 评分悬崖)+ 架构路线差异被误读(SparseFlex vs
等值面)+ 口碑测的本来就是另一些维度(速度/易用/纹理/价格)**。修正后 Tripo
v3/H3.1 回到第二梯队(77-82),P1 的低分依然成立。

---

## 1. 内部法医:v1 评分的"悬崖 bug"(主因,已修)

三轮 run 的逐边数据显示,Tripo 被判"不水密"的网格,**缺陷极其微小**:

| 网格 | 焊接后开放边 | 非流形边 | 总边数 | 缺陷占比 |
|---|---:|---:|---:|---:|
| tripo v3.0 h01 | 6 | 5 | ~90万 | 0.001% |
| tripo v3.0 p01 | 2 | 1 | ~140万 | 0.0002% |
| H3.1 c01 | 0 | 6 | ~220万 | 0.0003% |
| H3.1 h01 | 2 | 2 | ~210万 | 0.0002% |

v1 的 `is_watertight` 是二元一票否决(55+15 分归零)——**2 条坏边与满身破洞同罪**。
这些缺陷渲染不可见(用户看不到)、arena 评的是渲染图(评委看不到)、任何 DCC
一键修复(管线不在乎)。外部佐证:第三方 teardown 称 Tripo 中等复杂度模型
"典型呈现 50-200 条非流形边"(Neural4D,竞品出品需打折,但方向与我们实测一致)。

**修复(scoring v2)**:缺陷量级连续曲线(log10 分段)、部件闭合度
(closed_face_fraction)、fill-holes 可修复性。重算结果:v3.0 56→77.7、
H3.1 70.3→82.0;真破洞网格(TripoSR、TRELLIS 2、P1)依然低分。

## 2. 架构根因:SparseFlex vs 等值面提取(不是缺陷,是路线)

外部取证确认了一个此前未知的**架构分野**:

| 阵营 | 几何表示 → 网格提取 | 闭合性 | 证据 |
|---|---|---|---|
| **Tripo v3.0+** | **SparseFlex**(TripoSF)——"天然支持开放表面(布料、树叶)、任意拓扑" | **不保证闭合,by design** | TripoSF README 原文;Businesswire 3.0 发布稿 |
| Rodin | CLAY:占用场 + marching cubes | 构造性闭合 | CLAY 论文 (SIGGRAPH'24) |
| 混元 v2/2.1/2.5 | SDF + marching cubes | 构造性闭合 | 论文 + **源码直读**(surface_extractors.py) |
| Seed3D | SDF + dual marching cubes | 构造性闭合 | Seed3D 论文 (arXiv 2510.19944) |

**Tripo 用闭合性换了细节上限**(200 万面、"分离的手指、可读的浮雕文字"是 H3.1
的主打卖点)——竞品的等值面提取天然闭合但偏"糊"。我们 v1 的尺子恰好只量闭合,
等于给等值面阵营发了架构级免死金牌。

**Tripo 自己的 FDM 打印指南承认这一点**(原文):"原始模型由许多分离的面片
而非闭合水密实体构成……大概率触发切片错误",并推荐自家 Retopology 或 Blender
Merge by Distance 作为打印前置步骤。**Tripo 的产品模型是"生成 + 工具链管线"
(smart_low_poly / quad / 重拓扑按件收费),竞品是"开箱即闭合雕塑"**——测原始
输出对 Tripo 系统性偏严,但这也是其真实的开箱体验。

**订正一个我们此前的错误假设**:早先内部推测 Tripo 多组件输出是"游戏式分件构装
(眼睛/牙齿/发片分件)"——外部取证**未找到任何证据**;其默认输出是单网格
(SDK `generate_parts=False`),多组件实为 SparseFlex 面片。该表述已撤回。

## 3. 我们的焊接方法被外部验证为正确

研究代理下载并二进制解析了 3 个真实 Tripo GLB(10 万/2.8 万/32 万顶点):
- 默认导出**无压缩无量化**(纯 float32,无 Draco/quantization 扩展)
- UV 接缝的重复顶点**逐位相同**——**精确位置焊接把开放边 10,186→0、5,454→0、
  12,640→0**,即我们的焊接实现对真实 Tripo 文件有效
- 容差焊接反而危险:1e-5×对角线的容差会**误焊真实的独立顶点**(实测 18-60 处)
- 焊后残留的 2-6 条非流形边与我们的测量完全吻合

## 4. "口碑"到底在夸什么(与我们测的维度几乎不相交)

- **速度**:Tripo 最一致的强项(Turbo ~10 秒、P1 ~2 秒;竞品评测也承认)
- **易用性/一站式**:Studio 的分割/重拓扑/自动绑定全家桶
- **价格**:$19.9/月 3000 credits vs Meshy $20/月 1000
- **纹理**:H3.1 独立实测"极近距离下毛发纹理不糊"
- **评分平台注水提示**:Trustpilot 4.8 分,但有用户披露"留五星送 300 credits"
  ——头部好评部分是激励产生的
- **口碑同样存在的批评**:原始网格需清理("浮空几何、翻转法线、需 Blender 清理
  一遍")、自动绑定在关节处失败——**与我们的测量方向一致**,只是用户把它当作
  "AI 生成的正常代价",而非产品缺陷

## 5. Arena 到底怎么排(量化了本项目的原始假设)

HF 3D Arena 论文(arXiv 2506.18787)给出的偏好偏差**数字**:
- 高斯泼溅比网格 +16.6 ELO;同一模型的 splat 解码器比 mesh 解码器 **+78 ELO**
- **带纹理比素模 +144.1 ELO**(胜率 56.9% vs 32.4%)——arena 纹理偏好实锤
- **Tripo 商业模型根本不在 HF arena**(只有 2024 年的 TripoSR,第 17 名);
  其 "#1" 来自 top3d.ai(商业工具对战场,视觉投票,2026-07 当季 Tripo v3.1 居首)
- 跨平台最稳的是混元(HF 第7 / Hi3DEval 第1 / top3d 前3)——与我们 v2 榜单
  (混元 v2 93.6 居首)相互印证

## 6. 场景 × 指标矩阵(评测体系 v2 的结构)

| 场景 | 决定性指标 | 微缺陷态度 | v2 实现 |
|---|---|---|---|
| 打印/仿真 | 闭合度**量级**、可修复性、流形 | 一键可修≈无害 | 主榜(量级曲线+修复探测) |
| 游戏资产 | 面数预算、UV、拓扑、绑定 | 开放面片可以是设计 | 游戏榜(budget+UV) |
| 视觉/营销 | 纹理、相似度、美观 | 不可见 | 语义判官(VLM)+ 盲评画廊 |

## 7. 元教训

**基准与市场共识背离时,先假设尺子错了;把尺子修到无可指摘之后,剩下的背离才是
发现。**本案中:尺子错一半(悬崖 + 把架构路线当缺陷),发现也留下一半(P1 的
3% 缺陷边、TRELLIS 2 与 TripoSR 的低分、以及"Tripo 开箱输出确需清理"这一被
口碑淡化的事实)。
