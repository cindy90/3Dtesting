## 方法论注记:为什么官方价 vs fal 价不能放一列

1. **渠道加价/补贴不透明**:fal 对 Rodin 收 $0.4(官方列表 $0.75)——低于官方;对开源模型则是纯托管加价(混元 2.1 自托管 $0.009 vs fal ~$0.1,差 10 倍+)。方向不一,无法用一个系数换算。
2. **门槛不同**:Rodin 官方 API 要 $120/月订阅门槛,fal 免门槛——单价之外的准入成本完全不同。
3. **计价单位不同**:官方多为 credit/积分(且随订阅档折价浮动),fal 为按次美元;credit 真实价值取决于用户所在档位。
4. **含的东西不同**:官方档位常捆绑并发数、私有资产、优先队列;fal 只卖裸推理。

**因此本文档一律"官方价为主列、fal 价单独标注(参考)"。本测评的成本核算按实际使用渠道记录**(Tripo/Meshy/Seed3D 走官方,Rodin/混元v3.1/开源系走 fal——Rodin 因官方 $120/月门槛,fal 反而是合理选择,已在报告中注明)。
