## 与本测评的对应关系(实测印证,截至 run #10)

- 商业模型(Tripo v2.5、Meshy 6)在**纹理/观感**投入重,但**水密率 0%**、内部面高达 47% —— 正是公开 arena 偏好维度与生产维度的错位
- 开源混元 v2 **水密率 100%**、拓扑最干净(生产分中位 85.6 vs 商业 ~47)
- Tripo P1 / H3.1、Seed3D 2.0、混元 v3.1、Rodin 2.5 的"生产级"宣称 → 由**终极同代对决轮**验证
